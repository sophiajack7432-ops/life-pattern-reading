## [1.0.0] - 2026-11-05

### Added

- Initial public release of `life-pattern-reading`.
- Complete eight-stage workflow: mode selection, intake, data audit, chart fact sheet, independent readings, cross-system comparison, timeline, focus areas, and QA.
- L0–L4 reliability ladder and dual-chart protocol for boundary birth times.
- Four-system parameter ledgers for BaZi, Zi Wei Dou Shu, Qi Zheng Si Yu, and Western astrology.
- Evidence labels, confidence rubric, convergence breadth scale, and divergence registry.
- Safety policy covering high-stakes topics, crisis response, privacy, third-party readings, minors, and de-stigmatizing language.
- User intake form, report template, observation card, and ambiguity log.
- Three synthetic examples: full reading, partial data, and boundary time.
- `validate_skill.py` for package/frontmatter/link checks.
- `check_report.py` for report structure and deterministic/stigmatizing language lint.
- `package.py` for flat and bundle ZIPs with SHA-256 checksums.
- `install.ps1` and `install.sh` installers.
- Unit tests and GitHub Actions validation workflow.
