# 示例说明

这三个示例都使用**虚构资料与虚构盘面**，只用于演示输出结构、资料边界和语气，不对应任何真实人物。

| 示例 | 演示重点 |
|---|---|
| `full-reading.md` | 四体系都有资料时的完整结构；如何标注证据与置信度 |
| `partial-data.md` | 只有日期、没有出生时间时，如何不编造盘面 |
| `boundary-time.md` | 出生时间落在节气/日界/时辰边界时，如何降级结论 |

使用示例时请注意：

- 不要复制其中的出生资料或盘面字段当成真实数据；
- 不要因为示例里出现某个判断，就在真实解读中套用；
- 示例中的“示例排盘器 v0.0”是虚构来源，真实报告必须写清实际软件/版本/参数；
- 示例中的阶段表是格式演示，不是排运结论。
