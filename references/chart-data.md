# 盘面字段、参数与一致性检查

## 1. 共同出生资料台账

先把所有体系共用的资料记成一个台账。后面每个体系只引用这个台账，不各自猜测。

| 字段 | 记录内容 | 常见问题 |
|---|---|---|
| 日期 | 公历/农历、闰月 | 公历农历混用；闰月未标 |
| 时间 | 时:分、精确度、来源 | 只记得“早上”；把估算当记录 |
| 地点 | 城市、国家/地区、经纬度 | 城市跨度大；只给籍贯不给出生地 |
| 时区 | IANA 名称、UTC 偏移 | 默认 UTC+8；忽略夏令时 |
| 时间标准 | 钟表时/地方平太阳时/真太阳时 | 不知道是否做过经度校正 |
| 排盘来源 | 软件、网站、版本、日期 | 来源不明；参数不可复现 |
| 关注主题 | 用户真正想问的 | 把“看看命”扩写成全面预测 |

**事实与解释分开。** 台账只写“是什么”，不写“意味着什么”。

## 2. 四柱八字

### 2.1 必填字段

- 年柱、月柱、日柱、时柱（天干 + 地支）
- 日主（日干）
- 月令（月支）
- 藏干（若来源给出）
- 十神（若来源给出）
- 格局/旺衰（若来源给出，注明流派）
- 大运方向、起运岁数/交运日期、当前大运
- 流年（仅在需要流年分析时）

### 2.2 必须记录的口径

| 参数 | 常见选项 | 影响 |
|---|---|---|
| 年界 | 立春 / 正月初一 / 其他 | 年柱、流年 |
| 月界 | 节气（节） / 农历月 | 月柱、大运起排 |
| 日界 | 午夜 00:00 / 子初 23:00 | 日柱、时柱 |
| 子时 | 早子时/晚子时是否分 | 时柱、日柱 |
| 时间标准 | 钟表时 / 地方平太阳时 / 真太阳时 | 时柱、日柱边界 |
| 起运法 | 三天折一年 / 按分钟折算 / 其他 | 起运岁数、交运日期 |
| 大运顺逆 | 阳男阴女顺、阴男阳女逆 / 其他 | 大运方向 |
| 旺衰/格局 | 传统旺衰、盲派、新派等 | 解释结论 |

### 2.3 结构性检查

- 四柱是否为合法干支组合（六十甲子）；
- 月支是否落在相应季节（如寅卯辰为春）；
- 时支是否与出生时间范围相符（子时 23:00–01:00，依此类推）；
- 日主是否存在，十神是否能由日干与其他天干推出；
- 大运干支是否连续；
- 起运岁数与交运日期是否大致自洽。

**不要用模型记忆去“校正”日柱。** 如果用户给的日柱与日期看起来不一致，先问来源；无法确认就标为待核验。

### 2.4 不能编造

- 不要编造藏干、十神、神煞、格局；
- 不要编造大运起止年份；
- 不要在没有性别/年干阴阳时硬排大运顺逆；
- 不要把“日主强弱”当成客观测量；它是流派相关的解释。

## 3. 紫微斗数

### 3.1 必填字段

- 命宫、身宫
- 五行局
- 十二宫（命、兄、夫、子、财、疾、迁、友、官、田、福、父）
- 十四主星及其落宫
- 关键辅星/煞星（若来源给出）
- 四化（化禄、化权、化科、化忌）及所属天干
- 大限（起止年龄/宫位）
- 流年/小限（仅在需要时）

### 3.2 必须记录的口径

| 参数 | 常见差异 | 影响 |
|---|---|---|
| 农历/闰月 | 闰月按本月、下月、拆分等 | 命宫、月系星 |
| 晚子时 | 算当日/算次日 | 命宫、时系星 |
| 五行局 | 纳音/公式/其他 | 紫微星安放、大限 |
| 四化流派 | 全书/全集、中州派、飞星、三合等 | 四化星、解释 |
| 大限起法 | 起于命宫/兄弟宫、顺/逆 | 阶段表 |
| 星曜庙旺 | 不同表格 | 星曜强弱 |
| 三方四正 | 是否加会、夹拱 | 解释范围 |

### 3.3 结构性检查

- 十二宫是否齐全，宫名是否对应；
- 命宫、身宫、五行局是否给出；
- 十四主星是否基本齐全（不同流派可能有差异）；
- 四化是否与年干、流派一致；
- 大限起止是否连续，顺逆是否与规则一致；
- 流年命宫是否落在合理宫位。

### 3.4 不能编造

- 不要在不清楚闰月/晚子时规则时排命宫；
- 不要混用不同流派的四化表；
- 不要编造星曜庙旺、格局、神煞；
- 不要编造大限起止年龄；
- 不要用“某星入命所以一定……”的单星判断。

## 4. 七政四余

### 4.1 必填字段

- 命宫、命主（若来源给出）
- 十二宫
- 七政：日、月、水、金、火、木、土
- 四余：紫气、月孛、罗睺、计都
- 二十八宿/宿度（若来源给出）
- 大限、流年（仅在需要时）

### 4.2 必须记录的口径

| 参数 | 常见差异 | 影响 |
|---|---|---|
| 历法 | 农历/节气/其他 | 命宫、大限 |
| 星历 | 软件、版本、星历表 | 星体位置 |
| 坐标 | 黄道/赤道；回归/恒星 | 星度、宫位 |
| 宫制 | 等宫/象限/其他 | 十二宫 |
| 命宫起法 | 不同传统/软件 | 命宫、命主 |
| 罗睺/计都 | 平交点/真交点；升交点/降交点 | 四余位置 |
| 紫气/月孛 | 平均运动/星历/其他 | 四余位置 |
| 二十八宿 | 距星、宿度边界、岁差处理 | 宿度判断 |
| 时间标准 | 钟表时/真太阳时 | 命宫、上升 |

### 4.3 结构性检查

- 七政与四余是否齐全；
- 十二宫是否齐全；
- 二十八宿是否有宿度或至少宿名；
- 罗睺/计都是否成对，定义是否说明；
- 命宫/命度是否给出；
- 大限顺序是否连续。

### 4.4 特别说明

七政四余的流派、软件和参数差异很大。**没有来源、版本和关键参数时，不做精确星度、宫位、命宫或大限判断。** 可以讨论体系的历史背景与象征主题，但不能把模糊印象写成盘面事实。

## 5. 西方占星

### 5.1 必填字段

- 太阳、月亮、上升、天顶
- 行星落座与度数
- 行星落宫
- 主要相位（合、冲、刑、拱、六合等）
- 宫主星（若使用）
- 行运/次限/太阳弧/法达（仅在需要时）

### 5.2 必须记录的口径

| 参数 | 常见选项 | 影响 |
|---|---|---|
| 黄道 | 回归黄道 / 恒星黄道 | 星座、宫位 |
| 岁差 | 若恒星黄道，记录 ayanamsa | 星座度数 |
| 宫制 | Placidus、Whole Sign、Equal、Koch 等 | 宫位、宫主星 |
| 节点 | 真交点/平交点；北交点/南交点 | 节点解释 |
| 相位容许度 | 各行星/相位不同 | 相位是否成立 |
| 星历 | Swiss Ephemeris/JPL/其他及版本 | 行星度数 |
| 时区 | IANA、历史夏令时 | 上升、宫位 |
| 时间未知 | 太阳盘/正午盘/无宫位 | 可解释范围 |

### 5.3 结构性检查

- 行星度数是否在 0°–30°；
- 宫位是否 1–12，宫头是否按顺序；
- 上升/天顶是否给出；
- 太阳星座是否与出生日期大致相符；
- 相位容许度是否说明；
- 月亮是否因时间不明而可能换座。

### 5.4 时间未知时

- 可以讨论太阳星座、慢速行星的星座级主题（若星历可复现）；
- 不做上升、天顶、宫位、宫主星、月亮精确度数；
- 不使用“太阳盘”冒充本命盘；如使用，明确标注“太阳盘/正午盘，仅作临时参考”。

## 6. 四体系数据质量对照

| 体系 | 对时间敏感度 | 对地点敏感度 | 对流派/参数敏感度 | 缺时间时 |
|---|---|---|---|---|
| 八字 | 中（时柱、日界） | 低–中（真太阳时） | 中–高（旺衰/格局/起运） | 可保留年月日三柱，不排时柱/大运依赖项 |
| 紫微 | 高（命宫、时系星） | 低 | 高（四化/大限/闰月） | 通常不排完整盘 |
| 七政四余 | 高（命宫、宫位） | 高（经纬度） | 很高（星历/宫制/四余） | 通常不排完整盘 |
| 西方占星 | 高（上升/宫位） | 高（经纬度） | 中–高（宫制/黄道） | 可做太阳/行星星座级，不做宫位 |

## 7. 排盘工具适配

### 7.1 有可靠工具时

只有同时满足以下条件，才把工具输出当作 L3 盘面：

- 能记录工具名称、版本/日期、历法、时区、宫制、黄道、四化/大限等关键参数；
- 输入的是用户确认过的出生资料，没有让工具“猜时间”；
- 输出可以被复核（截图、文本、导出文件至少有一种）；
- 工具没有把解释性文字混进盘面字段。

使用步骤：

1. 先填出生资料台账，确认时间、地点、时区。
2. 按体系设置参数，逐项记录；不要用默认值却不注明。
3. 导出盘面字段，填进事实表。
4. 做结构性检查（见各体系小节）。
5. 如果用户已有另一份盘，做差异对照；不一致时不要平均。
6. 只把盘面字段带进解读；工具自带的“吉凶评分/断语”不作为事实。

不要在同一个盘里混用两个工具/流派的输出字段。比如用 A 软件的命宫、B 软件的四化，却没有说明，这会让后续判断无法复核。

### 7.2 没有星历/历法工具时

如果宿主没有可靠排盘工具，按以下顺序处理：

1. 请用户提供可信排盘结果；
2. 只对用户已经提供的盘面事实做解释；
3. 如果用户只有出生资料，输出“资料与口径 + 补盘清单”，不要自行推算；
4. 如果用户接受，改做不依赖盘面的主题反思；
5. 明确说明“本环境没有可用星历/历法数据，无法核实精确盘面”。

这不是能力不足的道歉，而是对结果可靠性的负责。
