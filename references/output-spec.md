## 2. 各节写法

### 2.1 资料与口径

必须包含：

- 出生日期、时间、地点、时区；
- 公历/农历、闰月；
- 时间来源与精确度；
- 现成盘面的来源、版本、关键参数；
- 资料等级（L0–L4）；
- 影响结论的不确定项。

示例：

```markdown
### 资料与口径
- 出生资料：公历 1992 年 3 月 18 日 07:40，成都，UTC+8；时间来源为家人口述，误差约 ±15 分钟。
- 排盘依据与采用口径：用户提供某排盘软件结果；八字用立春换年、节气换月、午夜换日；紫微用农历闰月按本月、晚子时算次日；西方用回归黄道、Placidus 宫制。
- 资料可信度：L3（盘面完整、参数可复现；未做第二来源核对）。
- 需要保留的不确定性：出生时间接近辰时边界，时柱与上升可能有两套方案；七政四余未提供星历版本，暂不做精确星度判断。
```

如果资料不足，不要编造。写清楚“目前不能做什么”。

### 2.2 总体格局

用 1 段话（80–150 字）概括主轴，然后列：

- 2–4 个优势；
- 1–3 个挑战；
- 2–3 个适合的发展方式。

主轴不是“命好/命差”，而是“这个人反复围绕什么主题展开”。

示例：

```text
这张盘的主轴更像是“在关系与自我表达之间寻找自己的位置”：既需要被看见、
被回应，也需要保留独立判断的空间。优势在于感知力、表达力和对关系的投入；
挑战在于容易过度顾虑他人反应，或在边界上反复拉扯。更适合的发展方式，是
把感受力转成可交付的表达/服务能力，同时保留独立创作或专业深度的空间。
```

### 2.3 四体系观察

固定四个标签：

- **四柱八字**：
- **紫微斗数**：
- **七政四余**：
- **西方占星**：

每套 100–250 字，1–3 个要点。没有资料就写：

```text
- **紫微斗数**：未提供出生时辰与可核验命盘，暂不做命宫/大限判断。
```

不要为了对称而硬写。四套体系不需要一样长。

每个要点尽量包含：

- 观察；
- 盘面依据；
- 置信度标签。

示例：

```text
- **四柱八字**：日主为丁火、月令卯木，表达与关系主题较突出。【八字·中】资源上更强调“以专业/作品换取空间”，而不是单纯追求规模；需要留意的是，容易在照顾他人与照顾自己之间失衡。
```

### 2.4 交叉结论

三个固定 bullet：

- 多体系共通主题；
- 各体系独有观察；
- 体系分歧与可能原因。

写法：

```markdown
- 多体系共通主题：两套体系都强调“表达与边界”的张力。【共通·2/4】
- 各体系独有观察：紫微更强调资源整合；西方占星更强调关系中的自主性。
- 体系分歧与可能原因：八字偏向“在结构中建立位置”，西方偏向“在关系中保留自由”。这可能来自体系关注点不同，也可能与出生时间误差有关；目前不强行调和。
```

只有一套可靠体系时：

```markdown
- 多体系共通主题：目前只有一套 L3 盘面，暂不做多体系共通判断。
- 各体系独有观察：……
- 体系分歧与可能原因：资料不足，暂不比较。
```

### 2.5 大运与人生阶段

表头固定为：

| 阶段 | 主要主题 | 机会与可用资源 | 需要处理的挑战 | 现实建议 |
|---|---|---|---|---|

表前写清：

- 时间来源；
- 年龄口径；
- 误差；
- 哪些阶段是命理排运，哪些只是通用阶段框架。

表后不要追加“逐年事件预测”。

如果无可靠数据：

```text
目前缺少可核实的大运/大限/行运数据，因此不列具体起止年份。下面只给
不依赖排运的阶段反思框架，不当作命理结论。
```

### 2.6 重点领域

根据用户关注选 2–4 个：

- 事业；
- 财务；
- 关系；
- 学习/迁移；
- 健康（仅在用户主动询问时）。

每个领域：

1. 一句主题判断；
2. 一句盘面依据；
3. 一个开放问题；
4. 1–2 个现实建议。

示例：

```markdown
#### 事业
盘面更强调“专业深度 + 自主空间”，而不是单纯的职位晋升。【八字·中】【西方·弱】
可以问自己：什么样的工作让我既能积累专业，又不必长期牺牲自主权？
现实建议：用 3 个月做一个小型独立项目，验证自己是否享受“从 0 到 1”的过程。
```

不要写“你应该辞职/转行/创业”。

### 2.7 总结

3–5 条，每条一个动作。动作要低风险、可逆、可在 1–3 个月内开始。

示例：

```markdown
1. 选一个主线技能，做 6 个月的深度投入，而不是同时铺开五个方向。
2. 每月记录一次“时间/金钱/精力”的分配，观察自己是否过度承担。
3. 在重要关系中练习一次“先表达需求，再讨论方案”的沟通。
4. 把命理结论当作假设，用现实反馈修正，而不是当作决定依据。
```

最后加边界声明。

## 3. 压缩版

用户要求短版时，保留：

- 资料与口径（3–4 行）；
- 总体格局（1 段）；
- 四体系观察（每套 1–2 句，或“资料不足”）；
- 交叉结论（2–3 条）；
- 阶段表（3 行以内，或说明无法列）；
- 总结（3 条）。

不要删除：

- 资料限制；
- 不确定项；
- 高风险转介；
- 边界声明。

## 4. 资料不足版

```markdown
### 资料与口径
- 已有：
- 缺失：
- 目前能做：
- 目前不能做：

### 总体格局
[只写不依赖缺失字段的内容，或说明暂不做]

### 四体系观察
- **四柱八字**：缺少出生时辰，暂不做时柱/大运判断。
- **紫微斗数**：缺少时辰，暂不排命宫。
- **七政四余**：缺少时辰/星历参数，暂不做。
- **西方占星**：缺少准确时间，暂不做上升/宫位。

### 交叉结论
资料不足，暂不做多体系比较。

### 大运与人生阶段
缺少可核实排运数据，不列具体起止。

### 重点领域
[开放问题 + 补资料建议]

### 总结
1. 先补齐出生时间/时区/地点。
2. 或提供可信排盘结果与参数。
3. 在补资料前，不把任何方向性描述当作盘面结论。
```

## 5. 证据标签

可用：

- `【八字·强】`、`【八字·中】`、`【八字·弱】`
- `【紫微·中】`
- `【七政·弱】`
- `【西方·中】`
- `【共通·2/4】`、`【共通·3/4】`、`【共通·4/4】`
- `【单体系】`
- `【待确认】`

规则：

- 每套体系最多 1–3 个标签；
- 标签放在句末，不打断阅读；
- 不用标签替代解释；
- 不把“强”写成“必然”。

## 6. 格式规则

- 中文标点为主；英文术语首次出现时加中文解释。
- 表格不超过 6 行（阶段表），列宽尽量均衡。
- 不用大量 emoji、感叹号、粗体轰炸。
- 引用传统术语时用引号或斜体，说明是传统概念。
- 不写“天机”“玄机”“泄露天机”等神秘化措辞。
- 不写“科学证明”“精准预测”“100%”。
- 不写“你必须”“你只能”“你别无选择”。

## 7. 报告检查清单

- [ ] 七个主 section 齐全；
- [ ] 四体系标签齐全（无资料也要写“无法判断”）；
- [ ] 资料等级与置信度匹配；
- [ ] 阶段表列名正确；
- [ ] 有边界声明；
- [ ] 没有事件预言；
- [ ] 没有羞辱性标签；
- [ ] 没有伪造体系一致；
- [ ] 有 3–5 条可行动建议；
- [ ] 长度适合用户需求。

可用 `python scripts/check_report.py <报告.md>` 做机械检查。

## 8. 常见错误

| 错误 | 修正 |
|---|---|
| 四套体系都写满，但三套没有资料 | 明确写“资料不足”，不硬凑 |
| 用“命中注定”解释一切 | 改成倾向、主题、条件 |
| 阶段表没有时间来源 | 补来源，或删除具体起止 |
| 只写优势，不写张力 | 至少一个需要投入的领域 |
| 只写问题，不写资源 | 先给优势与可用资源 |
| 交叉结论说“完全一致” | 改成“2/3 套呼应”，并写分歧 |
| 建议是“辞职/离婚/投资” | 改成低风险、可逆的小实验 |
| 没有边界声明 | 补上，且不要只放在文末小字 |
