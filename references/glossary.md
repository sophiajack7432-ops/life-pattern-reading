# 术语表

> 本表只帮助读者理解传统概念，不是完整教科书，也不是科学定义。不同流派对同一术语可能有不同解释；报告中应说明所用口径。

## 四柱八字

| 术语 | 简要解释 |
|---|---|
| 四柱 | 年柱、月柱、日柱、时柱，每柱由一个天干和一个地支组成 |
| 日主/日干 | 日柱的天干，传统上用来代表“自己”的核心符号 |
| 月令 | 月柱地支，代表出生时节的气候与主要环境 |
| 十神 | 以日干为中心，与其他天干/地支藏干形成的关系分类（比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印） |
| 藏干 | 地支中所藏的天干 |
| 通根/透干 | 天干在地支有根，或地支藏干透出天干 |
| 旺衰 | 日主在月令与全局中的强弱判断，流派差异较大 |
| 格局 | 对全局结构的传统分类，不同流派取法不同 |
| 大运 | 以十年为单位的阶段运势，起排需要方向与起运岁数 |
| 流年 | 某一年的干支，传统上用来观察年度主题 |
| 起运 | 从出生到进入第一步大运的时间 |
| 交运 | 进入新一步大运的时间点 |
| 真太阳时 | 按出生地经度与均时差校正后的太阳时 |
| 节气 | 太阳黄经达到特定角度的时点；月柱通常以“节”为界 |
| 立春 | 传统上常用的年界之一 |
| 子时 | 23:00–01:00；部分流派区分早子时/晚子时 |
| 虚岁 | 出生即 1 岁、过农历年加岁的计龄方式 |

## 紫微斗数

| 术语 | 简要解释 |
|---|---|
| 命宫 | 紫微斗数中代表自我核心的宫位 |
| 身宫 | 代表后天投入、身体与行动落点的宫位 |
| 五行局 | 由命宫干支决定的局数，用于安紫微星与起大限 |
| 十二宫 | 命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母 |
| 主星 | 紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军 |
| 辅星 | 左辅、右弼、文昌、文曲、天魁、天钺等辅助性星曜 |
| 煞星 | 擎羊、陀罗、火星、铃星、地空、地劫等，传统上视为压力/刺激符号，不等于灾祸 |
| 四化 | 化禄、化权、化科、化忌，依年干与流派安放 |
| 三方四正 | 本宫、对宫与三合宫位的组合 |
| 大限 | 紫微斗数中每十年一换的宫位阶段 |
| 小限 | 以年为单位的小周期，流派用法不同 |
| 庙旺利陷 | 星曜在不同宫位的强弱表，不同表格可能有差异 |

## 七政四余

| 术语 | 简要解释 |
|---|---|
| 七政 | 日、月、水、金、火、木、土 |
| 四余 | 紫气、月孛、罗睺、计都 |
| 紫气 | 传统四余之一，具体算法因流派/软件而异 |
| 月孛 | 传统四余之一，常与月亮远地点相关 |
| 罗睺 | 传统四余之一，常与升交点相关 |
| 计都 | 传统四余之一，常与降交点相关 |
| 命宫 | 七政四余中代表自我与人生重心的宫位 |
| 命度 | 命宫所落的度数 |
| 十二宫 | 传统宫位体系，名称与划分因流派而异 |
| 二十八宿 | 中国传统星空分区，宿度边界与岁差处理因体系而异 |
| 大限 | 七政四余的阶段周期 |
| 星历 | 计算星体位置的数据表/算法 |

## 西方占星

| 术语 | 简要解释 |
|---|---|
| 本命盘 | 出生时刻的行星、宫位与相位图 |
| 太阳星座 | 太阳所在星座，代表核心自我表达 |
| 月亮星座 | 月亮所在星座，代表情绪与安全感 |
| 上升/ASC | 出生时东方地平线升起的星座度数，代表外在应对方式 |
| 天顶/MC | 出生时子午线与黄道的交点，常与事业/公共形象相关 |
| 宫位 | 将星盘分为十二个生活领域；宫制不同，边界不同 |
| 宫主星 | 宫头星座的守护星 |
| 相位 | 行星之间的角度关系，如合、冲、刑、拱、六合 |
| 容许度 | 相位被认为有效的角度范围 |
| 行运 | 当前行星与本命盘的动态关系 |
| 次限 | 以一天代表一年的推进方法 |
| 太阳弧 | 以太阳弧推进的预测方法 |
| 法达 | 一种传统时间主星体系 |
| 回归黄道 | 以春分点为 0° 的黄道体系 |
| 恒星黄道 | 以恒星背景为参照的黄道体系，需要岁差参数 |
| 宫制 | Placidus、Whole Sign、Equal、Koch 等划分宫位的方法 |

## 时间与数据

| 术语 | 简要解释 |
|---|---|
| UTC | 协调世界时 |
| IANA 时区 | 如 `Asia/Shanghai` 的时区数据库名称 |
| 夏令时/DST | 某些地区在夏季把钟表拨快一小时的制度 |
| 地方平太阳时 | 按经度校正、但不含均时差的平均太阳时 |
| 真太阳时 | 按经度与均时差校正后的太阳时 |
| 星历 | 行星位置的数据来源，如 Swiss Ephemeris、JPL |
| 岁差 | 地球自转轴长期变化导致的恒星背景移动 |
| 交点 | 行星轨道与黄道的交点；罗睺/计都、北/南交点均与此相关 |

## 使用提醒

- 术语是工具，不是判决。
- 同一术语在不同流派中可能含义不同；报告要写清“按哪套口径”。
- 不要用术语堆砌制造权威感。
- 不要把传统术语直接翻译成现代心理诊断。
