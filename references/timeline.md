# 大运、大限与阶段轨迹

## 1. 原则

阶段轨迹不是“事件时间表”，而是“主题如何随时间变化”的假设。

只使用可核实的时间数据：

- 用户提供的排盘结果；
- 宿主可复现的排盘工具；
- 用户明确提供的 大运/大限/行运 表。

没有可靠数据时，**不列具体起止年份**，也不虚构“某年开始走好运”。

## 2. 时间数据台账

先记录，再解释：

```markdown
| 体系 | 周期名称 | 起止年份/年龄 | 年龄口径 | 来源/版本 | 误差/边界 | 置信度 |
|---|---|---|---|---|---|---|
| 八字 | 大运 |  | 周岁/虚岁 |  |  |  |
| 紫微 | 大限 |  | 虚岁 |  |  |  |
| 七政 | 大限 |  |  |  |  |  |
| 西方 | 行运/次限 |  | 周岁 |  |  |  |
```

不要把不同体系的周期强行对齐。它们可以大致重叠，但不是同一个时钟。

## 3. 年龄口径

| 口径 | 说明 | 处理 |
|---|---|---|
| 周岁 | 从出生日算起 | 默认使用 |
| 虚岁 | 出生即 1 岁，过农历年加岁 | 标注“虚岁”，必要时换算 |
| 起运岁 | 从出生到起运的时间 | 与“交运日期”区分 |
| 大限起始 | 紫微常用虚岁 | 不直接与周岁混排 |

同一张表里尽量统一口径；如果来源不同，必须在“阶段”单元格里注明。

## 4. 阶段表结构

标准表头：

| 阶段 | 主要主题 | 机会与可用资源 | 需要处理的挑战 | 现实建议 |
|---|---|---|---|---|

每行包含：

- **阶段**：年份/年龄范围 + 体系来源 + 误差；
- **主要主题**：1–2 个，不要塞满所有领域；
- **机会与可用资源**：哪些条件更顺手、可积累什么；
- **需要处理的挑战**：哪些地方需要投入、容易拉扯；
- **现实建议**：1–2 个低风险、可逆的动作。

示例（虚构，仅演示格式）：

| 阶段 | 主要主题 | 机会与可用资源 | 需要处理的挑战 | 现实建议 |
|---|---|---|---|---|
| 约 24–33 岁（示例大运；±1 年） | 建立专业身份；学会说“不” | 学习能力强；有可迁移的项目经验 | 容易同时接太多事；边界模糊 | 选一个主线技能做 6 个月；每月复盘一次时间分配 |

## 5. 各体系的阶段读法

### 5.1 八字大运

- 先看大运干支与原局的合冲刑害；
- 看大运是否引动日主、月令、财官印等关键主题；
- 看起运岁数与交运日期，避免把“起运”与“换运”混为一谈；
- 流年只作为“主题被引动”的补充，不做逐年事件预测。

### 5.2 紫微大限

- 看大限落在哪一宫、宫内主星与四化；
- 看大限三方四正；
- 看大限与命宫/身宫的关系；
- 记录大限起法是虚岁还是周岁、顺行还是逆行。

### 5.3 七政四余大限

- 看大限命宫/命度；
- 看七政四余在大限中的引动；
- 记录星历、宫制、命宫起法；
- 参数不完整时，不做精确起止。

### 5.4 西方行运

- 优先看外行星（土星、天王星、海王星、冥王星）对本命重要点的长期引动；
- 内行星行运只做短期节奏，不写成事件；
- 次限/太阳弧/法达只在有可靠数据时使用；
- 不用“某月必发生”句式。

## 6. 边界与误差

### 6.1 时间误差

如果出生时间有 ±X 分钟误差：

- 八字：可能改变时柱；若接近日界/节气，可能改变日柱/月柱；
- 紫微：可能改变命宫、时系星；
- 七政：可能改变命宫/宫位；
- 西方：可能改变上升、宫位；上升约每 4 分钟走 1°，时间误差越大，宫位越不可靠。

不要把误差“吸收”成一个精确结论。用范围表达：

```text
若出生时间在 07:30–08:00 之间，上升可能落在 A 或 B；
两个方案下都稳定的是……；只在 A 方案下成立的是……。
```

### 6.2 节气/换运边界

出生或换运落在节气、换运日、农历月边界附近时：

- 标注“边界敏感”；
- 列出两套可能时间；
- 只保留两套下都稳定的主题；
- 不硬选一个起止年份。

### 6.3 体系之间不一致

不同体系给出的阶段边界不同，是正常的。不要平均，不要伪造“共同起运年”。

可以写：

```text
八字大运约在 28 岁换运，紫微大限约在 30 岁换宫，西方土星回归约在 29–30 岁。
三个时间点不完全重合，但都指向 28–30 岁附近的“结构调整”主题。
```

## 7. 阶段主题的写法

### 7.1 机会

不要写“必发财/必升职”。写：

- “更适合积累某类能力”；
- “更容易遇到某类合作”；
- “适合做长期投入的窗口”；
- “可以尝试把兴趣转成可交付成果”。

### 7.2 挑战

不要写“必有大灾/必离婚”。写：

- “边界容易模糊”；
- “容易过度承担”；
- “对不确定性的耐受度受考验”；
- “需要注意资源分配与休息”。

### 7.3 建议

建议要具体、低风险、可逆：

- “用 3 个月做一个小项目验证”；
- “每月记录一次收支与风险决策”；
- “在冲突后 24 小时内做一次复盘”；
- “先短住/远程试运行，再考虑搬迁”。

不要：

- “辞职/离婚/卖房/All in”；
- “买某只股票/某个产品”；
- “停药/换医生”；
- “必须在某月前完成”。

## 8. 阶段数量

- 标准解读：3–5 个阶段；
- 深度解读：最多 6 个；
- 不要从 1 岁列到 80 岁；
- 不要逐年列流年；
- 用户只问“大方向”时，给 3 个阶段即可。

## 9. 没有可靠时间数据时

不要硬凑表。用下面的替代结构：

```markdown
### 大运与人生阶段

目前缺少可核实的大运/大限/行运数据，因此不列具体起止年份。可以先从“阶段主题”
的角度反思：

- 20–30 岁：建立能力与身份；
- 30–40 岁：资源整合与边界；
- 40–50 岁：重新评估“什么是值得的”。

这些不是命理排运结论，只是通用的人生阶段反思框架。若你提供排盘结果，
我可以再把各体系具体的阶段表补上。
```

清楚区分“通用阶段框架”和“命理排运结论”。

## 10. 阶段表检查

- [ ] 每个阶段都有时间来源；
- [ ] 年龄口径一致；
- [ ] 误差已标注；
- [ ] 没有事件预言；
- [ ] 机会/挑战不是“好/坏”二分；
- [ ] 每个阶段有 1–2 个可逆行动；
- [ ] 没有把不同体系的周期强行对齐；
- [ ] 没有精确到“某月某日”的断言。
